# Pasta gerada automaticamente

Esta pasta contém o JavaScript compilado a partir de `../ts/`.

**Não edite nem apague manualmente** — o navegador precisa destes arquivos para o painel funcionar.

## Gerar / atualizar

```bash
npm run build:mobilemoodle
```

Também roda automaticamente em `ionic serve` e `ionic build` (via gulp `mobilemoodle-ts`).

Fonte TypeScript: [`../ts/`](../ts/) — documentação em [`../ts/SCRIPTS-TS.md`](../ts/SCRIPTS-TS.md).
