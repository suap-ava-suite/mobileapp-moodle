MAPA TÉCNICO · REPOSITÓRIO REAL

Estrutura e Arquitetura do MoodleIFRN

O Moodle IFRN Mobile parte do aplicativo Moodle Mobile e acrescenta a experiência institucional do IFRN. As rotas Angular/Ionic, os serviços de identidade, o Painel web, a navegação nativa do Moodle e o runtime Cordova têm responsabilidades distintas.

Referência desta revisão: branch fix/ifrn-course-opening-phase2, HEAD inicial 9b3d24f50, em 13/11/2026. O worktree estava sujo. Confira o código e o Git antes de tratar esta página como estado de uma branch futura.

01 · FLUXO

Do Marketplace ao curso

  1. Marketplace IFRN: rota Angular /login/marketplace-ifrn apresenta a entrada e chama SuapEntryService.
  2. Autenticação SUAP: o fluxo usa navegador e redirecionamento institucional, valida o callback vinculado à tentativa e não cria senha própria no aplicativo. O serviço também mantém uma compatibilidade separada com OAuth Moodle quando o caminho de curso exige isso.
  3. Painel AVA: a rota /login/painel hospeda o Painel mobile. O iframe envia comandos de navegação sem credenciais; o host confere origem e janela de origem antes de aceitar mensagens.
  4. Curso: o host resolve o site Moodle, confirma identidade e matrícula exata e conduz o SSO oficial. A abertura termina em rota nativa do Moodle dentro do Ionic.
  5. Retorno: guardas e estado de navegação restauram o Painel quando a página do curso sai, preservando identidade e site ativos.
Marketplace → SUAP → Painel AVA → matrícula/identidade → SSO Moodle → curso nativo → Painel AVA

São contextos diferentes: sessão SUAP, dados/perfil do Painel, sessão salva por site Moodle e sessão de cada WebView. Não copie cookies ou tokens entre eles.

04 · INFRAESTRUTURA

Configuração, scripts e base Moodle

  • package.json/package-lock.json: scripts e versões; postinstall executa patch-package e instala dependências do plugin Moodle local.
  • angular.json: compila a aplicação e copia src/MoodleIFRN/mobilemoodle como mobilemoodle/.
  • config.xml: package ID, versão, plugins Cordova, recursos Android/iOS e hooks after_prepare.
  • src/MoodleIFRN/build-native.mjs: compila o alvo web Cordova e gera www/assets/lang/pt-br.json; --check valida o dicionário sem gerar arquivos.
  • npm run build:mobilemoodle: regenera bundles do Painel; não cria APK.
  • npm run patch:ifrn/patch-moodle-ifrn.js: pode alterar integração fora de MoodleIFRN; não é etapa segura e automática para qualquer tarefa.
  • scripts/cordova-hooks/ifrn-course-sso.js e src/MoodleIFRN/scripts/cordova-inappbrowser-layout.js: hooks executados no prepare. Revise platform e diffs após execução.
  • src/core/ é o núcleo Angular/Ionic do Moodle Mobile; src/addons/ contém módulos Moodle. Não modificar sem autorização explícita. Não altere OAuth, backend ou plugins nativos por conveniência.

Consulte build Android, teste no aparelho, testes e o manual antes de executar scripts.
